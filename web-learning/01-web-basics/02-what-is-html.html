Что такое HTML

Язык разметки, структура документа и первый опыт работы с кодом.

Цель: понять, что именно делает HTML, чем он отличается от CSS и JavaScript, как браузер превращает разметку в страницу и как проверить свои первые изменения. Этот урок можно проходить полностью офлайн.

1. Что такое HTML

HTML (HyperText Markup Language, язык гипертекстовой разметки) — язык, с помощью которого мы описываем содержание и смысловую структуру веб-документа: где заголовок, абзац, ссылка, изображение, список, форма и так далее.

HTML — не язык программирования: он не предназначен для записи алгоритмов, условий и циклов. Его основная задача — разметка документа. При этом современные HTML-элементы могут обладать встроенным поведением: например, ссылка открывает адрес, а элемент details раскрывает содержимое.

2. Разделение ролей: HTML, CSS и JavaScript

ТехнологияЗа что отвечаетПример
HTMLСодержание, структура, семантикаЗаголовок «Герои», список героев
CSSОформление и расположениеЦвет, размер текста, сетка карточек
JavaScriptЛогика и динамическое поведениеПоиск и фильтрация героев

Это разделение удобно, но не абсолютно: HTML имеет собственное поведение, CSS поддерживает интерактивные состояния, а JavaScript может изменять HTML и стили.

3. Из чего состоит HTML-документ

<!doctype html>
<html lang="ru">
<head>
  <meta charset="utf-8">
  <title>Мой первый сайт</title>
</head>
<body>
  <h1>Каталог героев</h1>
  <p>Здесь будут мои любимые герои.</p>
</body>
</html>

Это минимальный учебный пример, достаточный для знакомства с HTML. В реальных страницах обычно добавляют метатег viewport и другие данные. Каждый элемент мы подробно разберём в следующих уроках.

ЧастьНазначение
<!doctype html>Объявляет современный режим обработки HTML-документа; это не HTML-элемент.
<html lang="ru">Корневой элемент; атрибут lang указывает основной язык документа.
<head>Метаданные и подключения ресурсов, обычно не отображаемые как содержимое страницы.
<meta charset="utf-8">Указывает кодировку документа.
<title>Название вкладки браузера и документа.
<body>Содержимое документа, которое браузер представляет пользователю.
<h1>Заголовок первого уровня.
<p>Абзац текста.

4. Тег, элемент, атрибут: в чём разница

<p class="description">Это описание героя.</p>

Теги — записи <p class="description"> и </p>. Элемент — вся конструкция, включая теги и содержимое. Атрибут class="description" задаёт дополнительную информацию элементу. Не каждый элемент имеет закрывающий тег: например, img — пустой элемент.

Слово «тег» в повседневной речи иногда используют вместо «элемент», но технически это разные понятия.

5. Как браузер понимает HTML

Браузер читает HTML и строит внутреннее представление документа — DOM (Document Object Model). Упрощённо это дерево узлов. На основе DOM, CSS и других данных браузер рассчитывает отображение страницы.

document
└── html
    ├── head
    │   ├── meta
    │   └── title
    └── body
        ├── h1
        └── p

DOM — не то же самое, что исходный текст файла: браузер может исправлять некоторые ошибки разметки и дополнять дерево автоматически. Подробно разберём это позже.

6. Семантика: почему важно выбирать подходящий элемент

Посмотри на два варианта:

<div>Каталог героев</div>
<h1>Каталог героев</h1>

Оба могут показывать одинаковый текст. Но h1 сообщает, что это заголовок, а div — универсальный контейнер без собственного смыслового значения. Семантическая разметка помогает навигации, доступности и пониманию структуры документа. Она сама по себе не гарантирует высоких позиций в поиске.

7. HTML-файл и веб-сайт — не одно и то же

Файл page.html можно открыть прямо с диска по адресу file:///.... Для многих упражнений этого достаточно. Но сайт обычно включает несколько файлов, изображения, стили и скрипты, а в интернете передаётся через веб-сервер по HTTP(S).

При открытии через file: некоторые функции браузера могут быть ограничены. Позже мы научимся запускать локальный сервер, когда он понадобится.

8. Твой первый опыт: создай страницу

  1. Создай отдельную папку my-practice рядом с учебником (не внутри папки уроков).
  2. Создай в ней файл index.html в текстовом редакторе.
  3. Вставь пример из раздела 3 и сохрани файл в UTF-8.
  4. Открой его двойным щелчком в браузере.
  5. Измени текст внутри h1, сохрани файл и обнови страницу (Ctrl+R).

Обрати внимание: изменения в редакторе не появляются в браузере автоматически, если не настроено специальное обновление. Сначала сохрани файл, затем обнови вкладку.

9. Типичные ошибки

Путают имя файла и его расширение

Файл index.html.txt может открываться как обычный текст. Включи отображение расширений файлов и убедись, что расширение именно .html.

Пишут текст вне нужного элемента

<h1>Заголовок</h1>
<p>Описание</p>

Для обычного текста используй подходящие элементы. Не пытайся создавать структуру страницы с помощью пробелов и множества переносов строк.

Считают, что HTML определяет весь внешний вид

Браузер применяет встроенные стили к заголовкам и абзацам, но для управляемого дизайна нужен CSS. Например, крупный текст не обязательно является заголовком по смыслу.

Забывают обновить страницу

Если после изменения файла ничего не произошло, сначала проверь сохранение, правильный путь к файлу и обновление вкладки.

10. Практические задания

Уровень 1 — первые изменения

Создай страницу «Моя первая страница». Добавь один заголовок и два абзаца. Измени название вкладки на «Практика HTML». Открой файл и убедись, что заголовок вкладки отличается от заголовка на странице.

Уровень 2 — сравнение элементов

Добавь текст «Мои герои» сначала в div, затем в h2. Сравни их внешний вид без CSS. Письменно ответь: какой элемент лучше подходит для названия раздела и почему?

Уровень 3 — мини-страница каталога

Создай файл heroes.html с заголовком «Каталог героев», вводным абзацем и тремя подзаголовками h2 (например, названия классов героев). Под каждым подзаголовком добавь описание в p. Пока не используй CSS и JavaScript.

Подсказки к заданиям (открой после попытки)

Уровень 1: текст вкладки находится в title, видимый главный заголовок — в h1.

Уровень 2: h2 имеет смысл «заголовок второго уровня», а div не задаёт такую семантику.

Уровень 3: внутри body последовательно размести h1, p, затем три пары h2 + p.

Пример решения задания 3
<!doctype html>
<html lang="ru">
<head>
  <meta charset="utf-8">
  <title>Каталог героев</title>
</head>
<body>
  <h1>Каталог героев</h1>
  <p>Здесь я собираю информацию о героях.</p>
  <h2>Воины</h2>
  <p>Герои ближнего боя.</p>
  <h2>Лучники</h2>
  <p>Герои дальнего боя.</p>
  <h2>Маги</h2>
  <p>Герои, использующие магию.</p>
</body>
</html>

11. Самопроверка

  1. Что означает HTML и для чего он предназначен?
  2. Чем HTML отличается от CSS и JavaScript?
  3. В чём разница между тегом и элементом?
  4. Что такое атрибут?
  5. Что такое DOM?
  6. Почему h1 лучше подходит для главного заголовка, чем div?
  7. В чём разница между title и h1?
Показать ответы
  1. Язык гипертекстовой разметки; описывает содержание и структуру веб-документа.
  2. HTML — разметка, CSS — оформление, JavaScript — программная логика.
  3. Тег — запись в угловых скобках, элемент — соответствующая конструкция документа.
  4. Дополнительная информация или настройка элемента в открывающем теге.
  5. Объектное представление документа, построенное браузером.
  6. h1 имеет семантику заголовка, div — нет.
  7. title задаёт название документа (обычно вкладки), h1 — видимый заголовок содержимого.

12. Краткий конспект

  • HTML описывает структуру и смысл содержимого.
  • CSS оформляет страницу, JavaScript добавляет программное поведение.
  • HTML состоит из элементов; элементы могут иметь атрибуты.
  • Браузер разбирает HTML и строит DOM.
  • Правильная семантика важнее внешнего вида по умолчанию.
  • Для первых упражнений достаточно редактора и браузера.
