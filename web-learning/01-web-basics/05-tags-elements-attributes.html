Теги, элементы и атрибуты

Изучим синтаксис HTML, типы атрибутов, вложенность, пустые элементы и распространённые ошибки.

Как заниматься: прочитай теорию, воспроизведи пример в отдельной папке, выполни задания без подсказок. Ответы раскрывай после попытки.

1. Тег и элемент — не одно и то же

Тег — часть синтаксиса, например <p> или </p>. Элемент — узел документа, обычно образованный начальным тегом, содержимым и конечным тегом. Не все элементы имеют конечный тег. Различие полезно при обсуждении DOM и структуры страницы.

2. Открывающий и закрывающий теги

Большинство элементов записывается как <p>Текст</p>. Закрывающий тег содержит косую черту. Вложенные элементы закрываются в обратном порядке: сначала внутренний, затем внешний. Браузер может исправить некоторые ошибки, но результат иногда отличается от ожидаемого.

3. Пустые элементы

У некоторых элементов по правилам HTML нет содержимого и закрывающего тега: например, br, hr, img, input, meta, link. Запись <br /> допускается в HTML как синтаксический вариант, но косая черта не делает произвольный HTML-элемент самозакрывающимся: <div /> не закрывает div.

4. Атрибуты и их значения

Атрибуты записываются в начальном теге: <a href="page.html" title="Открыть страницу">Ссылка</a>. Имя атрибута и значение разделяет знак =. Для обучения используем двойные кавычки: так безопаснее при пробелах и специальных символах.

5. Булевы атрибуты

У булевых атрибутов наличие означает true, а отсутствие — false. Например, disabled отключает элемент формы. Запись disabled="false" всё равно означает включённый атрибут; чтобы убрать его действие, нужно удалить атрибут. Не путай это с aria-* и другими строковыми атрибутами.

6. Глобальные и специфические атрибуты

class, id, title, lang и data-* доступны многим элементам. href предназначен для определённых элементов, например a и link; src — для элементов, загружающих ресурс. Не каждый атрибут работает на любом элементе.

7. Регистр, пробелы и комментарии

В HTML имена обычных элементов и атрибутов нечувствительны к регистру, но принято писать их строчными буквами. Значения атрибутов могут быть чувствительны к регистру. Лишние пробелы в обычном тексте чаще всего схлопываются, но не везде.

8. Разбор примера

Перепечатай или скопируй пример в редактор. Если это структура папок, создай её вручную; если HTML — сохрани в файл с расширением .html. Проверь результат в браузере.

<p class="description" title="Подсказка">Описание героя</p>
<a href="heroes.html">Перейти к героям</a>
<input type="text" disabled>
<img src="hero.png" alt="Портрет героя">

Обрати внимание: пример предназначен для практики. Изменяй по одному элементу или атрибуту и наблюдай, как меняется результат.

9. Практические задания

Базовый уровень

Создай абзац с атрибутами class и title. Посмотри, как браузер показывает подсказку при наведении.

Средний уровень

Создай ссылку на соседний файл и изображение с alt. Измени значение атрибута и посмотри на результат.

Сложный уровень

Создай input с disabled="false". Проверь, доступно ли поле для ввода, затем полностью удали атрибут и объясни различие.

Подсказки к практике

Сначала проверь: файл действительно сохранён, расширение верное, браузер обновлён, а путь к файлу совпадает с его расположением. Сравни свою структуру с примером выше. Для сложного задания объедини несколько приёмов из урока.

10. Самопроверка

  1. Чем тег отличается от элемента?
  2. Почему <div /> не закрывает div в HTML?
  3. Что означает наличие disabled="false"?
  4. В каком теге записывают атрибуты?
  5. Всегда ли href работает на любом элементе?
  6. Почему рекомендуется брать значения атрибутов в кавычки?
Показать ответы
  1. Тег — запись разметки, элемент — конструкция/узел документа.
  2. В HTML div не является пустым элементом и не самозакрывается такой записью.
  3. Булев атрибут присутствует, поэтому поле отключено.
  4. В начальном (открывающем) теге.
  5. Нет, атрибут имеет определённые допустимые контексты.
  6. Это уменьшает ошибки, особенно когда значение содержит пробелы.
