Урок 1. Как работает интернет

Браузер, сервер, адрес сайта, запрос и ответ — простыми словами.

Цель: понять, что происходит при открытии сайта, чем интернет отличается от веба и где в этой цепочке находится HTML.

1. Интернет и Всемирная паутина — не одно и то же

Интернет — глобальная сеть взаимосвязанных компьютерных сетей. По ней передаются разные виды данных: веб-страницы, электронная почта, сообщения, файлы и многое другое.

Веб (World Wide Web, WWW) — одна из служб, использующих интернет. Веб состоит из ресурсов, связанных адресами (URL) и часто гиперссылками. Браузер получает их, как правило, по протоколам HTTP или HTTPS.

Аналогия: интернет — дорожная сеть, а веб — одна из служб доставки, пользующаяся этими дорогами. Аналогия упрощённая, но помогает не путать понятия.

2. Клиент, сервер и браузер

ПонятиеЧто означает
КлиентПрограмма, отправляющая запрос. Например, браузер.
СерверПрограмма или компьютер, предоставляющий данные и обрабатывающий запросы.
БраузерПрограмма, которая получает веб-ресурсы, интерпретирует HTML/CSS и выполняет JavaScript.

Один компьютер может быть и клиентом, и сервером. Слово «сервер» в разговоре иногда означает машину, а иногда — серверную программу.

3. Что происходит при открытии сайта

  1. Ты вводишь адрес, например https://example.com/.
  2. Браузер определяет, куда отправить запрос. При необходимости используется DNS — система, сопоставляющая доменные имена с сетевыми адресами.
  3. Браузер устанавливает соединение с нужным узлом. Для HTTPS используется защищённое соединение.
  4. Браузер отправляет HTTP-запрос на ресурс.
  5. Сервер возвращает HTTP-ответ: статус, заголовки и, если предусмотрено, тело ответа (например, HTML).
  6. Браузер разбирает HTML, запрашивает дополнительные ресурсы (CSS, изображения, скрипты) и строит страницу.

Это упрощённая последовательность: DNS может быть закеширован, соединения могут переиспользоваться, а ресурсы загружаться параллельно. Поэтому не нужно представлять все шаги как строго последовательные при каждом открытии страницы.

4. Из чего состоит адрес URL

https://example.com:443/catalog/hero.html?class=mage#skills
ЧастьЗначение
httpsСхема (протокол доступа)
example.comИмя хоста
:443Порт (для HTTPS обычно подразумевается)
/catalog/hero.htmlПуть к ресурсу
?class=mageСтрока запроса
#skillsФрагмент — обычно указание на часть документа; браузер не отправляет его в HTTP-запросе

5. HTTP и HTTPS

HTTP — протокол обмена запросами и ответами между клиентом и сервером. HTTPS — HTTP поверх защищённого соединения (TLS): оно шифрует передаваемые данные и помогает проверить подлинность сервера.

Частые коды ответа: 200 — успешный запрос, 301 — постоянное перенаправление, 404 — ресурс не найден, 500 — внутренняя ошибка сервера. Код 200 не гарантирует, что содержимое страницы правильно с точки зрения HTML.

6. Как связаны HTML, CSS и JavaScript

ТехнологияОсновная задача
HTMLСтруктура и смысл содержимого: заголовки, абзацы, ссылки, изображения, формы.
CSSВнешний вид и расположение элементов.
JavaScriptЛогика и интерактивность: реакция на действия, изменение страницы, работа с данными.

Это распределение ролей, а не жёсткая граница: HTML тоже имеет встроенные интерактивные возможности, а JavaScript может влиять и на структуру, и на оформление.

7. Локальная страница и сайт на сервере

Если открыть HTML-файл двойным щелчком, браузер обычно использует адрес вида file:///.... Это удобно для изучения HTML, но отличается от открытия сайта по http:// или https://. Например, некоторые возможности JavaScript, запросы к файлам и маршрутизация могут вести себя иначе из-за ограничений безопасности.

Для первых уроков достаточно локальных HTML-файлов. Когда дойдём до JavaScript и запросов, научимся запускать локальный сервер.

8. Первый пример HTML

Создай файл hello.html и помести в него следующий код:

<!doctype html>
<html lang="ru">
<head>
  <meta charset="utf-8">
  <title>Моя первая страница</title>
</head>
<body>
  <h1>Привет, мир!</h1>
  <p>Я изучаю веб-разработку.</p>
</body>
</html>

Сохрани файл в кодировке UTF-8 и открой в браузере. Увидишь крупный заголовок и абзац. Пока необязательно запоминать все теги — подробно изучим их в следующих уроках.

Что важно заметить

  • <title> задаёт название вкладки, а не видимый заголовок страницы.
  • <h1> обозначает главный заголовок содержимого.
  • <p> обозначает абзац.
  • Браузер показывает результат разметки, а не сами теги.

9. Типичные ошибки

  • «Интернет и браузер — одно и то же». Нет: браузер — программа, работающая в том числе с интернетом.
  • «HTML — язык программирования». HTML — язык разметки: он описывает структуру и смысл документа.
  • «Любой HTML-файл обязательно должен лежать на сервере». Нет: простую страницу можно открыть локально.
  • «Если я вижу страницу, значит сервер отправил один готовый файл со всем содержимым». Необязательно: браузер часто загружает множество ресурсов, а часть содержимого может создаваться динамически.

10. Практика

Уровень 1 — первый документ

Создай папку my-first-site, внутри — index.html. Измени в примере заголовок вкладки, видимый заголовок и текст абзаца. Открой страницу в браузере.

Проверка: отличается ли текст на вкладке от заголовка внутри страницы?

Уровень 2 — изучение URL

Разбери адрес https://example.com/heroes/list.html?type=archer#top: найди схему, хост, путь, строку запроса и фрагмент. Запиши ответ в текстовом файле.

Уровень 3 — исследование браузера

Открой любой доступный тебе сайт, нажми F12 (или открой инструменты разработчика через меню браузера), найди вкладку Network / Сеть и перезагрузи страницу. Посмотри, какие типы ресурсов загружаются: Document, CSS, JS, Img. Если сайт недоступен или ты офлайн, просто пропусти это задание.

11. Самопроверка

  1. Чем интернет отличается от веба?
  2. Что делает браузер после получения HTML?
  3. В чём разница между клиентом и сервером?
  4. Для чего нужен DNS?
  5. Чем HTTPS отличается от HTTP?
  6. Почему локальный HTML-файл не во всём ведёт себя как сайт по HTTPS?
Показать ответы для самопроверки
  1. Интернет — сеть сетей; веб — служба, использующая эту сеть.
  2. Разбирает разметку, запрашивает нужные ресурсы и отображает документ.
  3. Клиент запрашивает ресурсы, сервер отвечает на запросы; это роли программ.
  4. Помогает определить сетевой адрес для доменного имени.
  5. HTTPS защищает обмен HTTP с помощью TLS.
  6. У схемы file: другой контекст безопасности и ограничения браузера.
Показать подсказки к практике

Уровень 1: меняй содержимое <title>, <h1> и <p>.

Уровень 2: схема — https; хост — example.com; путь — /heroes/list.html; запрос — type=archer; фрагмент — top.

Уровень 3: в Network можно увидеть отдельные запросы, статусы ответов и типы загружаемых ресурсов. Не на каждом сайте встретятся все перечисленные типы.

12. Краткий конспект

  • Интернет — сеть, веб — служба поверх неё.
  • Браузер выступает клиентом, а сервер отвечает на запросы.
  • URL указывает, как и где искать ресурс.
  • HTTP передаёт запросы и ответы; HTTPS добавляет защиту соединения.
  • HTML отвечает прежде всего за структуру, CSS — за оформление, JavaScript — за программную логику.
  • HTML-файлы можно изучать офлайн.
