Элементы link, style и base

Подключение CSS и иконок, встроенные стили и управление базовым адресом относительных ссылок.

Как заниматься: изучи объяснения по порядку, создай отдельную папку для экспериментов, набери примеры самостоятельно, затем выполни задания. Подсказки и ответы раскрывай после попытки.

1. link — связь с внешним ресурсом

Элемент <link> связывает текущий документ с другим ресурсом. Он не создаёт обычную кликабельную ссылку в тексте: для этого нужен <a>. Значение rel описывает отношение, href — адрес. Самый частый вариант — таблица стилей.

<link rel="stylesheet" href="styles.css">

При открытии HTML-файла локально относительный путь вычисляется относительно адреса документа, если не задан base. Убедись, что styles.css лежит рядом с HTML.

2. Основные значения rel

relНазначениеПример
stylesheetПодключить CSS<link rel="stylesheet" href="style.css">
iconИконка сайта<link rel="icon" href="favicon.svg" type="image/svg+xml">
canonicalПредпочтительный URL для индексирования<link rel="canonical" href="https://example.com/page">
preloadРанняя загрузка нужного ресурсаТребует корректного as и понимания приоритетов
preconnectРаннее установление соединенияПолезно лишь для реально нужных внешних источников

Не добавляй preload или preconnect автоматически: неправильные подсказки могут тратить ресурсы. canonical — сигнал для поисковых систем, а не жёсткий редирект.

3. style — встроенные CSS-правила

Элемент <style> позволяет написать CSS прямо внутри документа, обычно в head. Правила применяются к элементам body. Это удобно для небольшого примера, но в большом проекте отдельный CSS-файл обычно проще поддерживать и переиспользовать.

<style>
  body { font-family: sans-serif; }
  h1 { color: navy; }
</style>

4. Атрибуты link и загрузка ресурсов

У link встречаются media, type, sizes, crossorigin, integrity, referrerpolicy, fetchpriority. Их смысл зависит от типа связанного ресурса. Для обычного CSS чаще всего достаточно rel="stylesheet" и href. Указание type="text/css" обычно не требуется.

<link rel="stylesheet" href="print.css" media="print">

Этот CSS применяется в контексте печати. Не путай атрибут media у link с медиафайлами.

5. base — изменение базового адреса

Элемент <base> задаёт базовый URL для относительных ссылок документа. Допускается не более одного base с href и не более одного с target; если они присутствуют, должны находиться в head. Это влияет не только на обычные ссылки, но и на пути к изображениям, стилям и другие URL, поэтому может неожиданно сломать сайт.

<head>
  <base href="https://example.com/catalog/">
</head>
<body>
  <a href="heroes.html">Герои</a>
</body>

Ссылка heroes.html теперь разрешается как https://example.com/catalog/heroes.html. Даже ссылки вида href="#chapter" могут вести на базовый URL с фрагментом, а не на текущий локальный файл. Для учебного сайта с локальными страницами лучше обходиться без base.

6. base target и безопасность

Атрибут target у base задаёт цель по умолчанию для ссылок и форм, которые не указали свою цель. Это редкий приём. Не следует без необходимости открывать все ссылки в новых вкладках. При использовании target="_blank" полезно понимать поведение noopener; современные браузеры обычно не дают новой вкладке доступ к opener по умолчанию для ссылок с _blank, но явное rel="noopener" делает намерение очевидным.

Для файловой офлайн-структуры рекомендуем относительные пути и обычные ссылки без base.

7. Типичные ошибки

  • Перепутать link и a: первый подключает ресурс, второй создаёт ссылку в содержимом.
  • Указать путь styles.css, хотя файл лежит в папке css/.
  • Вставить base без понимания влияния на все относительные URL.
  • Ожидать, что CSS внутри style появится как текст страницы.
  • Добавлять preload на каждый ресурс без измерений.

8. Практические примеры

Подключение отдельного CSS

Создай index.html и styles.css рядом друг с другом.

<!doctype html>
<html lang="ru">
<head>
  <meta charset="utf-8">
  <title>Каталог</title>
  <link rel="stylesheet" href="styles.css">
</head>
<body>
  <h1>Каталог героев</h1>
</body>
</html>

/* Содержимое styles.css: */
h1 { color: darkgreen; }

Встроенные стили

Проверь, что стиль применяется, хотя в body нет CSS-текста.

<head>
  <style>
    h1 { color: teal; }
  </style>
</head>

9. Практические задания

Базовый уровень

Создай index.html и styles.css; подключи файл через link и измени цвет заголовка.

Средний уровень

Добавь favicon.svg (можно взять собственный SVG-файл) и отдельный print.css; проверь в DevTools, что файлы находятся по верным путям.

Повышенная сложность

В отдельной тестовой папке создай две HTML-страницы и поэкспериментируй с base href; объясни, как изменился адрес ссылки href="second.html" и href="#top". Затем убери base.

Подсказки к заданиям
  • link rel="stylesheet" подключает CSS.
  • style содержит CSS внутри HTML.
  • base влияет на относительные URL всего документа.

  3. Когда удобно использовать style?
  4. Что меняет base href?
  5. Почему base нежелателен для нашего офлайн-учебника?
  6. Всегда ли нужен type="text/css"?
Показать ответы
  1. link объявляет связь с ресурсом, a создаёт гиперссылку в содержимом.
  2. Подключает таблицу стилей.
  3. В небольших примерах или для специфических встроенных правил.
  4. Базовый URL для разрешения относительных ссылок.
  5. Он может изменить адреса ссылок и ресурсов, включая якоря.
  6. Нет, для обычного stylesheet он необязателен.

11. Краткий конспект

  • link rel="stylesheet" подключает CSS.
  • style содержит CSS внутри HTML.
  • base влияет на относительные URL всего документа.
  • Для офлайн-проекта удобнее относительные пути без base.
