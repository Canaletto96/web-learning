Структура HTML-документа

Подробно разберём doctype, html, head, body, lang, charset и viewport.

Как заниматься: прочитай теорию, воспроизведи пример в отдельной папке, выполни задания без подсказок. Ответы раскрывай после попытки.

1. Каркас HTML-документа

В начале документа обычно пишут <!doctype html>, затем корневой элемент html, внутри которого находятся head и body. <!doctype html> — декларация типа документа, а не HTML-тег. Она помогает браузеру использовать современный режим отображения.

2. Корневой элемент html и язык

html — корневой элемент документа. Атрибут lang="ru" сообщает основной язык содержимого, что помогает программам чтения с экрана, поисковым системам и другим инструментам. Для английской страницы используй lang="en". Если фрагмент на другом языке, его язык можно указать отдельно.

3. Раздел head

head содержит метаданные: кодировку, название документа, настройки отображения, ссылки на CSS и другие ресурсы. Большая часть его содержимого не выводится как обычный текст на странице. Элемент title задаёт название документа, обычно показываемое во вкладке.

4. Раздел body

body содержит основное содержимое документа: заголовки, абзацы, ссылки, изображения, формы и многое другое. Видимость зависит от CSS, поведения элементов и браузера: не всё, что находится внутри body, обязательно видно.

5. Кодировка UTF-8

<meta charset="utf-8"> объявляет кодировку. Располагай объявление кодировки как можно раньше в head; спецификация требует, чтобы оно целиком находилось в первых 1024 байтах документа. Файл также должен быть фактически сохранён в UTF-8.

6. Viewport для мобильных экранов

<meta name="viewport" content="width=device-width, initial-scale=1"> задаёт типичную конфигурацию области просмотра на мобильных устройствах. Без него мобильный браузер может использовать виртуальную широкую область просмотра, уменьшая страницу целиком.

7. Вложенность и порядок

Элементы должны быть правильно вложены: закрывай внутренний элемент до внешнего. В HTML некоторые закрывающие теги могут быть необязательными, но в учебных примерах мы будем писать их явно для понятности. Текст с угловыми скобками в обычном содержимом следует экранировать.

8. Разбор примера

Перепечатай или скопируй пример в редактор. Если это структура папок, создай её вручную; если HTML — сохрани в файл с расширением .html. Проверь результат в браузере.

<!doctype html>
<html lang="ru">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Каталог героев</title>
</head>
<body>
  <h1>Каталог героев</h1>
  <p>Добро пожаловать!</p>
</body>
</html>

Обрати внимание: пример предназначен для практики. Изменяй по одному элементу или атрибуту и наблюдай, как меняется результат.

9. Практические задания

Базовый уровень

Создай корректный HTML-документ с русским языком, кодировкой UTF-8, viewport, названием вкладки и одним абзацем.

Средний уровень

Создай две страницы с разными title и h1. Сравни название вкладки и видимый заголовок.

Сложный уровень

Создай страницу с английским абзацем lang="en" внутри русскоязычного документа. Проверь дерево элементов в DevTools и объясни, почему язык можно менять на уровне фрагмента.

Подсказки к практике

Сначала проверь: файл действительно сохранён, расширение верное, браузер обновлён, а путь к файлу совпадает с его расположением. Сравни свою структуру с примером выше. Для сложного задания объедини несколько приёмов из урока.

10. Самопроверка

  1. Является ли doctype HTML-элементом?
  2. Чем отличаются head и body?
  3. Где отображается title?
  4. Для чего нужен lang?
  5. Что задаёт meta viewport?
  6. Достаточно ли объявить UTF-8, если файл сохранён в другой кодировке?
Показать ответы
  1. Нет, это декларация режима обработки документа.
  2. head содержит метаданные, body — содержимое документа.
  3. Обычно во вкладке браузера, а также используется другими программами.
  4. Указывает язык документа или фрагмента.
  5. Типичную ширину и масштаб области просмотра на мобильных устройствах.
  6. Нет, фактическая кодировка файла должна соответствовать объявлению.
